# 位置与完整摆放：冻结统计

对应[阶段报告](../../reports/layout-stage-20261027.md)。两轮均为已消费历史数据上的开发回放：74 局、277 个出价前前缀，结算标签只用于评分。默认模型和 beta.7 二进制保持不变。

## 文件

| 文件 | 内容 |
|---|---|
| `geometry-replay.json` | 几何实验的原始聚合评分、两种子结果与按局 bootstrap 区间 |
| `full-layout-replay.json` | 完整摆放的原始聚合评分、稳定性、回退策略与按局 bootstrap 区间 |
| `protocols.json` | 两轮预算、加预算规则、随机种子及支持修正说明 |
| `checks.json` | 几何和概率验证摘要、约束检查、顺序检验及位置密度统计 |
| `manifest.json` | 公开文件的 SHA-256、字节数，以及私有来源文件的逻辑名称与哈希 |

两个 `replay.json` 保留正式实验聚合评分文件的全部字段与数值，仅按仓库规则统一为 LF 换行。其余文件按白名单提取聚合字段，省略案例索引、会话标识和本机路径；没有逐局预测、结算记录或协议包。来源哈希仅用于追溯，不表示这些私有来源已公开。

## 读数口径

`per_game_equal` 内的主评分先在局内平均，再让每局等权；`decision_mape_pct` 和 `common_stable_decision_mape` 是逐前缀口径。MAPE 和覆盖率的值均以百分数表示，例如 `15.541` 表示 15.541%；对应差值为百分点。区间为 P10–P90，`interval_score`、`width` 和 `interval_width` 均以游戏价值单位计，报告展示时除以 10,000 写成“万”。区间评分同时惩罚宽度和区间外误差，越小越好。

置信区间按局 bootstrap 10,000 次，并不涵盖重复探索同一历史样本的选择偏差。两轮使用不同预算和种子，不可跨文件相减得出模型收益。

完整摆放的 `raw` 策略仅在两个种子均无支持时回退对照；`gated` 策略要求对照和候选同时通过稳定性门槛，否则回退。完整布局 `raw` 回退 41 个前缀，`gated` 回退 208 个前缀，全部 277 个前缀均保留。`layout` 自身稳定 73 个前缀，与对照同时稳定的有 69 个。

几何实验若任一种子无支持，就对该前缀的实验输出采用对照回退；完整布局实验的回退政策与它不同。所有低 ESS 结果和无支持情况均有计数，不应把原始评分视为全部案例已经收敛。

耗时是两种子离线任务记录，完整布局的 `height`、`layout` 耗时只计额外摆放计算，不含数值候选生成；不同阶段并发不同，不能作为现场延迟。

## 核验与复现边界

在仓库根目录运行：

```bash
python scripts/verify_public_release.py
```

该命令检查公开材料边界和清单中的哈希、字节数，不重新执行私有实验。逐局输入、候选池和完整实验管线未随本次发布；仅凭此目录不能独立重跑 277 个前缀。这里公开的是可审阅的聚合证据，结论仍为“尚未可靠胜出”，不构成默认模型升级或实时工具验收。
