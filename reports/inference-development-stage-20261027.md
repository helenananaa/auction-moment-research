# 让线索真正进入估值：推理改进的阶段性结果

2026-10-27。整理模型改进目录中的最终报告和冻结统计；与[独立世界模型研究](world-model-stage-20261027.md)共同发布。

## 改进发生在哪里

**此前主要的问题是已有线索没有被充分用起来。** v6 能从整体特征给出估值，却不能保证每一个平均值、总值和揭示计数都成立。早期 v2 的条件计算又会因候选过少而失败或放宽条件。研究先修条件推理，再讨论是否要换生成先验。

main 已包含精确约束采样、并行计算、后台细化、揭示信息转换和默认被动抓包输入。本次补齐它们的研究依据与后续修正，不把研究目录的旧原型再复制成另一套运行时。

## 先核对线索，再决定怎样使用

在 1,284 局严格清洗的公开地图上，按终局重新计算事件公式，一致率为 99.4–100%。取整平均值、品质总值和尺寸计数都有明确含义；按品质揭示位置、按尺寸揭示轮廓，提供的通常是对应组的精确数量。模拟事件值复现了 3,695 个真实值中的 3,692 个。

条件后验因此要在这些约束内抽地图。品质总值用精确求和处理，尺寸平均价转换成整数总值区间，身份和品质揭示进入概率权重，地图行数通过经验似然约束总面积。这里的“精确”主要指被纳入的整数约束，不代表坐标、揭示选择过程、行数似然和采样误差全部精确。

最初的重建方案在候选过少时放宽筛选，277 个前缀中有 154 个放宽、18 个低有效样本量。后续精确约束方案通过改变抽样方式改善支持度，避免把放松条件当作最终解决办法。尺寸平均值分组缓存也已修复为按分组缓存，避免不同分组之间复用错误索引。

## 同一批旧对局上的变化

下表保留各阶段原始口径，便于解释改进来自哪里。它们是开发回放，不是独立重复试验；不同采样设置不能简单相减后归因于某一个改动。

| 阶段 | 277 个前缀的点误差 MAPE | 含义 |
|---|---:|---|
| v6 | 22.48% | 冻结对照 |
| 早期重建 v2，取 P50 | 约 19.1% | 更充分利用线索，但部分约束仍放宽 |
| 同一早期后验，取 MAPE 最优点 | 约 17.4% | 按损失函数选择点估值，不等于后验本身改变 |
| 后续协议输入精确约束回放 | 15.61% | `app-exact-report` 的 `protocol_4lanes` |
| 最终抓包路径回放 | 15.57% | `arms-packet-report` 的 `packet`；按局等权为 15.81% |

这些数字都来自 74 局、277 个已消费前缀，真实视觉输入、抓包链路和完整现场一局没有因此获得验收。最新世界模型比较另用共同适配器、训练内行数表和局级等权评分，其 v2 基线为 15.660%；不能把两份报告之间的小差异全算作先验收益。

## 还有哪些研究值得保留

| 研究问题 | 结果 | 对产品的含义 |
|---|---|---|
| 彩色还留下多少不确定性？ | 在公开验证对局上，给定全部非彩色身份和彩色件数的经验 oracle，误差仍约 13.12%；一件彩色时约 20.04% | 彩色是重要剩余来源；这是特定 oracle 的结果，不是不可突破的数学误差下界 |
| 加对手之前的出价是否更准？ | 756 份后续轮次决策中，增量约 +0.14 个百分点，95% 区间 [−0.29,+0.56] | 没有稳定额外收益，不应据此增加运行时复杂度 |
| 个人事件是否存在固定最佳选择？ | 402 局、1,157 份决策，交叉拟合静态策略相对实际选择 −0.193 个百分点，95% 区间 [−0.546,+0.156] | 没有稳定优胜；事后挑最好事件的收益不能变成可用策略收益 |
| 地图行数是否重要？ | 精确模型去掉行数，开发误差约从 15.6% 升到 19.3% | 正确读取行数值得保留 |
| 简单经验公式是否还有价值？ | 行数、金色总值、金紫件数能构成透明的非彩色估值公式 | 保留 README 的速查公式，并注明它们不直接估彩色 |
| 更复杂的速度方案是否等于实时成功？ | 并行、预热、后台细化改善了离线计算路径 | 仍需返场后端到端验收，不能把线程或缓存测试当作现场可用性 |

早期报告先观察到了彩色的相关性，再提出 700 万筛选和有限重试解释。后续独立研究指出，终局数据支持的是分布层面的价值抑制，不能唯一反推硬门槛或重抽顺序。原来的 B2、均匀彩色加硬门槛等实验保留为假说历史；不会以“已找到原因”的口气放回新版 README。
