# 研究候选 R2 与 KG_mix2

这两个 JSON 是第 27 轮历史回放使用的 `BASE/G` 候选的终局生成分布。它们用于离线研究，不被助手自动加载，不替换 `world-model-v2-S.json`。

| 内容 | 说明 |
|---|---|
| 训练数据 | 2026-08-04 以前的 1,556 局；私有结算未随参数公开 |
| 评估 | 已消费 74 局、277 个前缀；区间评分改善，点误差未明确胜出 |
| 结构 | 两个潜在类型；R2 为规模和预留品质，KG 为品质相关停止 |
| 身份 | 类型 × 品质 × 最终 N 的归一化概率；使用公开 C 编号 |
| 总价 | 平滑正概率权重；超过约 700 万仍有概率 |
| 输出 | 终局总件数、品质数、总价、总面积；不输出真实坐标或出价 |
| 依赖 | NumPy；不需要私有结算、DLL、PyTorch 或助手模型下载 |
| 单位 | 金额为游戏原单位，宽度 30,000；N 的行依次对应 10–60 |

`components[].base_n_probabilities` 在 R2 中是类型内规模分布，在 KG 中是用于计算基准停止率的参考分布。两者再经过整局价值权重后，最终分布都会变化。`weight` 同样是价值筛选前的类型权重。

身份概率直接导出自冻结适配器；计数递推和价值权重的便携实现已与原适配器核对，见[导出回执](../../results/world-model-stage-20261027/export-parity.json)。这验证了导出计算的一致性，不增加真实样本。

运行方式与完整机制见[阶段报告](../../reports/world-model-stage-20261027.md)。公开生成器没有重新训练入口；完整历史重训需要未公开的数据及研究环境。两种候选仍有高价尾部残差，未完成前瞻校准和实盘收益验证。
